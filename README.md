# Mohsen Hazrati

I am an MSc student in physics at Middle East Technical University (METU). I use numerical models to study low-temperature discharges. I also work on vorticity and helicity in relativistic ideal fluids.

## Research code

| Project | Contents |
| --- | --- |
| [Maxwellian electron-impact rates](https://github.com/mohsenhazratimetu/maxwellian-rate-coefficients) | Python code to convert cross sections to rate coefficients, with analytical checks and output tables for COMSOL. |
| [DC argon glow discharge](https://github.com/mohsenhazratimetu/comsol-dc-glow-discharge) | One-dimensional and axisymmetric models exported through the COMSOL Java API, with geometry files and build instructions. |
